# Sanitised Markdown preview and copy

Issue #13 introduces one sanitised render model for Project and Task descriptions. Markdig parses the CommonMark structure; dot-orbit converts that syntax tree into its own small block and inline model before anything reaches preview or clipboard output. Raw HTML nodes are removed, links accept only `http`, `https`, `mailto`, or local fragments, and remote images become inert `[Remote image not loaded: alternative text]` placeholders. Approved absolute web and email links become keyboard-focusable native hyperlinks; local fragments remain inert until the preview has in-document navigation targets. The preview never loads remote content itself.

The accepted subset covers paragraphs, six heading levels, emphasis, strong text, inline and fenced code, safe links, block quotes, thematic breaks, ordered lists, unordered lists, line breaks, and standard character entities such as `&nbsp;`. Lower-alpha ordered markers such as `a.` and `b.` are the one deliberate convenience beyond the CommonMark list syntax. Loose-list paragraph breaks, mixed nested list hierarchy through at least four levels, and the boundary between adjacent Markdown blocks are preserved consistently in preview, HTML, and plain text. The native preview gives semantic block changes visible vertical space while keeping consecutive items in one list compact. As in standard Markdown, repeated empty source lines collapse to one block boundary; an `&nbsp;`-only paragraph provides an intentional additional spacer. Other Markdown extensions, embedded media, and remote image loading remain outside this slice.

Descriptions open in rendered preview mode. The preview is a focusable edit surface exposed with button semantics whose accessible name includes both the rendered plain-text content and the edit action: pointer activation, Space, or Enter switches to the multiline Markdown source editor. Hyperlinks are independent descendants, so activating one launches its approved destination without triggering edit mode. Moving focus away or completing a pointer click anywhere outside the editor returns to the sanitised rendering without saving the wider inspector draft or taking focus from the next control. While editing, Tab and Shift+Tab indent or outdent the current line by one four-space Markdown level. Indenting a numeric or lower-alpha ordered item converts it to an unordered sub-point; unordered items retain their marker and plain text remains plain indented text. Enter continues the resulting marker with the current indentation, and Control+Tab or Control+Shift+Tab retains normal focus traversal. List continuation remains inactive inside fenced or standalone indented code. The render model updates with every source change, so the returned preview and subsequent copy reflect the current draft. Empty content retains an instructional activation target.

**Copy rendered** sends both platform-native HTML and universal plain text in one clipboard operation. Windows receives a CF_HTML envelope with byte offsets; macOS uses `public.html`; Linux uses `text/html`. The two representations are serialised from the same render model shown by preview. Clipboard content is neither read back nor logged, and success or failure is announced with fixed non-sensitive status text.
