# Domain document routing

dot-orbit uses a single domain context.

- Read `CONTEXT.md` before domain-sensitive implementation or review.
- Read `docs/adr/` for accepted decisions affecting the issue.
- Add an ADR when a decision is costly to reverse, crosses module boundaries, or changes a domain invariant.
- Update `CONTEXT.md` when canonical language or invariants change.
- Do not treat the HTML prototype as the only behavioural specification; reconcile it with product requirements and ADRs.
