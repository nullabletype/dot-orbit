# Contributing to dot-orbit

dot-orbit is still establishing its architecture and first useful release. Please open or join an issue before starting a feature or behavioural change. Pull requests for those changes should implement an accepted, linked issue rather than introduce an unsolicited feature.

Small documentation corrections and clearly isolated bug fixes may be opened directly as pull requests.

Before submitting a change:

- read `AGENTS.md` and the relevant product, domain, design, architecture, and development documents;
- keep the change bounded and preserve unrelated work;
- use only current, supported dependencies and tooling with reproducible pins and lockfiles;
- use fictional or synthetic examples and do not include personal data, credentials, or local environment details;
- run the relevant automated and manual checks and record evidence for the tested commit; and
- follow `docs/development/github-artifact-policy.md` without exception.

Internal APIs have no compatibility guarantee before the first stable release.

Report security vulnerabilities privately as described in `SECURITY.md`, not through a public issue.
