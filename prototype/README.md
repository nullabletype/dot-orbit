# dot-orbit clickable prototype

Open `index.html` in any modern desktop browser. No installation, account, or build step is required.

All names, projects, tasks, dates, and descriptions in the prototype are fictional sample data.

## What to try

- Switch between **Workbench**, **Canvas**, and **Ledger** with the floating prototype control. The chosen direction is reflected in the `?variant=` URL and the left/right arrow keys also cycle it.
- Move through Today, Task backlog, Projects, Categories, Completed, and Archive.
- Drag tasks in Today or Task backlog to change one shared task order. Reordering either view updates the other.
- Drag projects in Projects to maintain a separate chronological/manual project order. Subtasks can also be reordered inside their project without changing Today or Backlog.
- Use Categories for the grouped view of every project, and drag category headings to maintain an independent category order.
- Expand a project and complete its remaining tasks. The project closes when the last task is completed and takes that task's completion date.
- Select a task to change its category from inherited to overridden, inspect its participants, or add/remove it from Today.
- Select a project or task, then edit its title, dates, category, participants, or Markdown directly in the details panel. Project status is derived from its subtasks.
- Use **Copy rendered** to place both rich HTML and plain text on the clipboard for pasting into Teams, Word, or another rich-text editor.
- Search the Archive with the search field or press `/`.

All changes are temporary sample state and reset when the page is refreshed.
